BOSS DIALOGUE
Interview question bank.
40 questions with answer guidance. Answer aloud before opening the guidance, and use your own examples rather than memorising a script.
SQL · 10 questions
1. What is the difference between WHERE and HAVING?
Answer direction:
WHERE filters rows before aggregation; HAVING filters grouped results. Show a total-sales example.
2. What is the difference between INNER and LEFT JOIN?
Answer direction:
Explain which rows are preserved, unmatched NULLs and the importance of the join key.
3. Why did revenue double after a join?
Answer direction:
Check the grain and key uniqueness. A one-to-many join can duplicate fact rows; aggregate or fix the key, do not hide it with DISTINCT.
4. What is the difference between COUNT(*), COUNT(column) and COUNT(DISTINCT column)?
Answer direction:
All rows, non-NULL values and distinct non-NULL values respectively.
5. How would you get the top three products per category?
Answer direction:
Aggregate to product/category grain, then use ROW_NUMBER or DENSE_RANK depending on the tie policy.
6. How do you find customers with no orders?
Answer direction:
LEFT JOIN + unmatched-key IS NULL, or NOT EXISTS; explain NULL risks with NOT IN.
7. When would you use a CTE?
Answer direction:
To express logical steps clearly. It is not automatically a performance improvement.
8. How would you calculate month-on-month change?
Answer direction:
Aggregate by month, use LAG and divide the difference by the prior value with zero handling. Consider absent months.
9. How do you handle missing values?
Answer direction:
Decide what NULL means, use IS NULL and only COALESCE when the replacement is semantically justified.
10. How would you validate your result?
Answer direction:
Check row counts, grain, key uniqueness, totals, sampled cases and an independent calculation.
Excel & data quality · 10 questions
1. When would you use XLOOKUP rather than a PivotTable?
Answer direction:
A lookup returns related values by key; a pivot summarises data. Check key uniqueness and the desired grain.
2. How would you clean a messy CSV?
Answer direction:
Preserve raw data, inspect types, dates, blanks and duplicates, then document and reconcile each transformation.
3. What is a repeatable Power Query workflow?
Answer direction:
Typed import → cleaning steps → merge/unpivot → validation → refreshable output. Test on a replacement file.
4. What is the difference between a blank and zero?
Answer direction:
A blank may be unknown or not applicable; zero is an observed value. They can change counts and averages differently.
5. How do SUMIFS and COUNTIFS help?
Answer direction:
They aggregate by multiple criteria. Explain a date-bounded category-sales example.
6. How do you check a lookup is correct?
Answer direction:
Use exact matching, inspect unmatched values, test duplicates and sample returned records.
7. How would you build a manager’s weekly report?
Answer direction:
Clarify decision, definitions and audience; automate import, reconcile totals, then present a small number of useful KPIs.
8. What is percentage-point change?
Answer direction:
A rate moving from 10% to 12% rises by 2 percentage points or 20% relative—not 2% relative.
9. Why might Excel show dates incorrectly?
Answer direction:
Locale, mixed text/date types or serial formatting; parse deliberately and inspect ambiguous dates.
10. What would you do if two reports disagree?
Answer direction:
Compare sources, refresh times, grain, filters, date boundaries and definitions before deciding which is wrong.
Power BI, statistics & Python · 10 questions
1. Why use a star schema?
Answer direction:
Clear fact/dimension grain, predictable relationships and reusable measures; explain your own model.
2. What is the difference between a measure and a calculated column?
Answer direction:
A measure evaluates at query time in filter context; a column is computed per row and stored during refresh.
3. What does CALCULATE do?
Answer direction:
Evaluates an expression in modified filter context. Demonstrate using a measure from your project.
4. How would you test a dashboard?
Answer direction:
Reconcile KPIs, test slicers and relationships, inspect blanks, zero denominators, dates and accessibility.
5. When is median more useful than mean?
Answer direction:
Often when a distribution is skewed or affected by outliers; explain both with a simple example.
6. Does correlation prove causation?
Answer direction:
No. Confounding, selection bias and reverse causality may explain an association.
7. How do you explain uncertainty to a manager?
Answer direction:
Describe the range, assumptions, sample/data limits and what additional evidence would change the decision.
8. How would you validate a pandas merge?
Answer direction:
Inspect key uniqueness, use validate= where appropriate, track unmatched rows and reconcile totals and counts.
9. How do you make a notebook reproducible?
Answer direction:
Record source versions and dependencies, use clear relative paths and re-run from a fresh environment in order.
10. Should you use Publish to web for a company report?
Answer direction:
No for confidential data: it makes content publicly accessible. Use approved sharing, access controls and licensing.
